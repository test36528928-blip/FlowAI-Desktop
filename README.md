# # FlowAI Desktop

FlowAI is an open-source desktop AI assistant built with Python.

## Features

- AI-powered conversations
- Local chat history using SQLite
- Custom system instructions
- Light and dark themes
- Gemini API key entry through the application

## AI Model

FlowAI is configured to use **Gemini 3.8 Flash**.

## Requirements

- Windows
- A Google Gemini API key

## Getting Started

1. Download the latest Windows executable from the repository's Releases section when available.
2. Launch `FlowAI.exe`.
3. Enter your Gemini API key when prompted.
4. Start chatting.

## Privacy

Chat history is stored locally on the user's device. The API key entered through the application is held in memory and is not saved by the application code shown in this repository.
